# TOMAT GROW — Versi Portable / EXE

Aplikasi monitoring tanaman tomat dalam **satu paket Python** yang dapat:
- Dijalankan langsung sebagai script, **atau**
- Dikompilasi menjadi `.exe` untuk Windows.

Semua template HTML, CSS, dan JavaScript sudah dibundel di dalam Python
(`tg_ui.py`) — tidak perlu file eksternal.
